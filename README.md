# Wordle

A minimal, dark-themed Wordle and Quordle clone in **English** and **Afrikaans**, with adjustable word length and unlimited replays.

**Play it here: https://l0sttpro.github.io/wordle/**

## Features

- **Two modes:** Wordle (1 board, 6 guesses) and Quordle (4 boards, 9 guesses)
- **Two languages:** English and Afrikaans, each with a large word list
- **Variable word length:** 4 to 7 letters, chosen from a dropdown
- **Play as much as you like:** Random mode gives a new word every game, Daily mode gives everyone the same puzzle each day
- **Smart keyboard:** on-screen and physical keyboard support, with Quordle keys showing one colour stripe per board
- **Proper duplicate-letter handling:** repeated letters are scored the same way as the original game
- **No dependencies:** plain TypeScript, HTML and CSS, bundled with Vite

## How to play

Guess the hidden word in the allowed number of tries. After each guess, every tile changes colour:

| Colour | Meaning |
| ------ | ------- |
| Green  | Right letter, right position |
| Gold   | Right letter, wrong position |
| Dark   | Letter is not in the word |

In Quordle you solve four words at once, and every guess is applied to all four boards.

Afrikaans words are played without diacritics, so `môre` is entered as `more` and `reën` as `reen`.

## Run it locally

Requires [Node.js](https://nodejs.org/) 18 or newer.

```bash
git clone https://github.com/YOUR-USERNAME/wordle.git
cd wordle
npm install
npm run dev
```

Then open the URL Vite prints (usually http://localhost:5173).

To create a production build:

```bash
npm run build
npm run preview
```

## Project structure

```
src/
  main.ts            app entry: settings, input handling, rendering
  types.ts           shared types
  config.ts          game modes and word-length range
  game/
    evaluate.ts      guess scoring (two-pass, handles duplicate letters)
    random.ts        seeded random picks for Daily mode
    state.ts         Game class: guesses, win/lose, keyboard state
  words/
    index.ts         loads and filters word lists by language and length
    en.ts / af.ts    word list loaders
    data/            generated word lists
  ui/
    board.ts         board and tile rendering
    keyboard.ts      on-screen keyboard
scripts/
  build-words.mjs    downloads and builds the word lists
```

## Word lists

The word lists are generated by `scripts/build-words.mjs`, which downloads the sources below and writes the results to `src/words/data/`. Each language has an **answers** list (common words used as secret words) and an **allowed** list (every accepted guess).

```bash
node scripts/build-words.mjs
```

Sources:

- English answers: [google-10000-english](https://github.com/first20hours/google-10000-english) (no-swears list)
- English guesses: [dwyl/english-words](https://github.com/dwyl/english-words)
- Afrikaans frequency data: [FrequencyWords](https://github.com/hermitdave/FrequencyWords) (OpenSubtitles)
- Afrikaans spelling dictionary: [LibreOffice dictionaries](https://github.com/LibreOffice/dictionaries) (`af_ZA`, LGPL)

To block a word from ever being a secret word, add it to the `BLOCK` set in the script and run it again.

## Deployment

The site is deployed to GitHub Pages by the workflow in `.github/workflows/deploy.yml`. Every push to `main` builds the project and publishes the `dist/` folder.
